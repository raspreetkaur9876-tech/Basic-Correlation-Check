
# Basic Correlation Check

## Project Overview
This project performs correlation analysis on the Iris dataset using Python.

## Objectives
- Calculate correlation between numerical variables.
- Create a correlation matrix.
- Visualize relationships using a heatmap.
- Create scatterplots.
- Identify important observations.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
Iris Dataset (150 records and 4 numerical features).

## Visualizations
1. Correlation Heatmap
2. Sepal Length vs Petal Length
3. Sepal Width vs Petal Width

## Key Observations
1. Petal length and petal width have a strong positive correlation.
2. Sepal length and petal length have a positive correlation.
3. Sepal width and petal length have a negative correlation.

## How to Run
1. Install required libraries:
   pip install pandas matplotlib seaborn scikit-learn

2. Run the Python file:
   python correlation.py
