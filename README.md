
# 📊 Basic Correlation Check

## 📌 Project Overview
This project performs basic correlation analysis using the Iris dataset. It identifies relationships between numerical variables and visualizes them using heatmaps and scatterplots.

## 🎯 Objectives
- Calculate correlation between numerical variables.
- Generate a correlation matrix.
- Visualize correlations using a heatmap.
- Create scatterplots to compare variables.
- Identify positive and negative relationships.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 📂 Dataset Information
Dataset: Iris Dataset

- Total Records: 150
- Numerical Features: 4

Features:
1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

## 📈 Project Visualizations
1. Correlation Matrix
2. Correlation Heatmap
3. Sepal Length vs Petal Length
4. Sepal Width vs Petal Width

## 🔍 Key Observations
1. Petal length and petal width have a strong positive correlation.
2. Sepal length and petal length have a positive correlation.
3. Sepal width and petal length have a negative correlation.

## ⚙️ Installation

Install the required libraries:

```bash
pip install pandas matplotlib seaborn scikit-learn
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install the required libraries.
4. Run the Python file:

```bash
python correlation.py
```
